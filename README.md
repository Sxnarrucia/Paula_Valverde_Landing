# Paula Valverde — Landing Page

## Cómo correrlo localmente

```bash
npm install
npm run dev
```

Abrí http://localhost:3000

## Antes de lanzar

Editar `src/lib/constants.ts` con los datos reales:
- Número de WhatsApp de Paula
- Correo
- Links de redes sociales

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (tokens de color/tipografía en `tailwind.config.ts`)
- Framer Motion para animaciones
- next/font para Poppins (títulos) e Inter (contenido), auto-hospedadas
